# TouchType Pro

TouchType Pro is a focused touch typing practice web application built with React and Vite.

The application helps users practice the eight home-row keys:

A S D F J K L ;

## Features

- Custom practice duration
- Default 5-minute practice
- 1, 2, 3, 5, 10, 15 and 20 minute goals
- Beginner mode
- Accuracy mode
- Speed mode
- Four difficulty levels
- Live timer
- Keys pressed
- Correct keys
- Incorrect keys
- Accuracy percentage
- WPM
- Next-key highlighting
- Virtual keyboard
- Per-key mistake analysis
- Personalized improvement suggestions
- Early session stopping
- Practice history
- Achievement badges
- Daily practice streak
- LocalStorage progress
- Responsive UI

## Tech Stack

- React
- Vite
- JavaScript
- CSS3
- Lucide React
- Browser LocalStorage
